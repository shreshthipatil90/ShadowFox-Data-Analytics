# Superstore Sales Analysis and Dashboard

### ShadowFox Virtual Internship – Beginner Level Data Analyst

## Project Overview
This project focuses on analysing the Sample Superstore dataset to understand business performance through sales, profit, product categories, and regional analysis.

## Objectives
- Analyse sales and profit performance.
- Calculate important business KPIs.
- Identify monthly sales trends.
- Compare product category performance.
- Analyse regional profitability.
- Create a dashboard using Google Sheets.

## Dataset
**Dataset Name:** Sample Superstore Dataset

**Source:** Kaggle

https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

The dataset contains information about orders, customers, products, sales, profits, quantities, and regions.

## Tools and Technologies
- Google Sheets
- Spreadsheet Formulas
- Pivot Tables
- Charts and Data Visualization

## Key Performance Indicators
| KPI | Value |
|---|---:|
| Total Sales | $2,297,200.86 |
| Total Profit | $286,397.02 |
| Total Orders | 5,009 |
| Total Quantity Sold | 37,873 |
| Average Order Value | $458.61 |

## Key Business Insights
- Technology recorded the highest sales among the three product categories.
- November recorded the highest monthly sales.
- The West region generated the highest profit among the regions analysed.
